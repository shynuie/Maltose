# 聊天面板實施計畫

日期：2026-10-31。狀態：依修正後規格重整第一版；桌面視覺驗證待可用的 WindowServer 環境。

## 目標與範圍

新增一個純 UI 聊天面板，展示目前 session 的訊息內容。聊天面板不放輸入框；訊息輸入沿用窗口底部既有輸入欄。本階段使用本地示意 session，不接 Agent、服務、資料庫或磁碟持久化。

「面板模式」指單一面板全屏顯示。工作空間保留全局模式、單一面板模式、面板＋側欄模式三種既有模式。

## 已確認規格

| 項目 | 規則 |
| --- | --- |
| 面板用途 | 顯示聊天訊息內容，不是單獨的 session 列表。 |
| 輸入框 | 聊天面板內不顯示輸入框；沿用窗口底部輸入欄。 |
| 全局模式 | 顯示目前 session 的聊天內容，不顯示 session 選擇列表。 |
| 單一面板模式 | 左側顯示 session 列表，右側顯示目前 session 聊天內容；點選 session 後在同一面板切換。 |
| 滾動 | 全局模式可滾動目前聊天；單一面板模式下 session 列表與聊天內容各自可滾動。 |
| 單一面板文字欄 | 右側聊天閱讀欄約每行 40 個中文字；左側 session 選擇欄較窄且固定。 |
| 全局模式文字欄 | 面板大小變化時調整字級，目標約每行 20 個中文字；面板太窄而無法以可讀字級顯示時隱藏文字。 |
| Current session | 在單一面板模式選擇的 session 成為目前 session；切回全局模式後顯示該 session。 |

「40 個中文字」與「20 個中文字」是閱讀欄寬度的設計目標，以中文字型實際字寬安排，不硬性截斷訊息字數。

## 模式呈現

- **全局模式**：只顯示目前 session 的聊天內容，使用響應式字級與約 20 字寬的閱讀欄。普通滾動停在聊天面板上時滾動訊息；工作區空白處仍滾動全局網格，Ctrl＋滾動仍縮放網格。
- **單一面板模式**：使用左右分欄。左側 session 列表獨立滾動並標示目前 session；右側顯示聊天內容，閱讀欄最大約 40 個中文字寬。選擇 session 只切換右側內容，不建立新面板。
- **面板＋側欄模式**：沿用目前 session 的聊天內容與寬閱讀欄，不提供 session 選擇；session 切換只在單一面板模式進行。
- **輸入**：窗口底部既有輸入欄在三種工作區模式中維持固定；聊天面板不再重複放置輸入控制。

全局模式文字尺寸使用可讀下限；低於下限時隱藏訊息文字，不再縮小到難以閱讀。若文字隱藏，面板保持原本 Glass 與 Content 框架。

## 純 UI 資料與狀態

第一版提供多個固定示意 session，每個包含標題、最近更新時間及數則 user／assistant 訊息，涵蓋長短訊息以檢查捲動與換行。初始 current session 為最近更新的項目。Session 選取只存在記憶體中，窗口模式切換不清除目前選擇，重啟後可重設。

暫不納入真實對話同步、搜尋、篩選、重新命名、刪除、未讀狀態、Agent 即時新增訊息、訊息發送，以及跨重啟保存。

## 驗收標準

| 場景 | 必須滿足 |
| --- | --- |
| 全局模式 | 顯示 current session 的聊天訊息，不出現 session 側欄或面板內輸入框。 |
| 全局響應式文字 | 約 20 個中文字一行；縮小到字級下限仍無法閱讀時隱藏文字且不溢出。 |
| 全局滾動 | 聊天面板內普通滾動只瀏覽訊息；工作區空白處普通滾動瀏覽網格；Ctrl＋滾動縮放網格。 |
| 單一面板模式 | 左側 session 列表與右側聊天內容並列；側欄與訊息內容可獨立滾動。 |
| Session 切換 | 只在單一面板模式選擇 session；不建立新面板，並立即顯示該 session 訊息。 |
| Current session 保留 | 切回全局模式時顯示最後在單一面板模式選取的 session。 |
| 面板＋側欄模式 | 顯示 current session 的寬版聊天內容，不顯示 session 選擇側欄。 |
| 輸入欄 | 窗口底部既有輸入欄保持固定；聊天面板內沒有第二個輸入框。 |
| 純 UI 範圍 | 所有 session 與訊息均為本地示意資料，不啟動 Agent 或外部服務。 |

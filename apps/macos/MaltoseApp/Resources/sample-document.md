# Maltose 工作空間

這是一份內建的 **Markdown 範例文件**，用來檢視標題、段落、清單、程式碼、表格與圖片在文件面板中的呈現。你可以選取文字並使用 `⌘C` 複製。

## 讓內容保持清楚

文件面板是唯讀瀏覽器。文字欄會依顯示模式改變寬度，而圖片會保留原本比例，隨可用空間縮放。

> 在全局模式中，文字太小而難以閱讀時會暫時隱藏；圖片仍會縮小並保留完整畫面。

## 常用格式

- **粗體文字**和*斜體文字*可以快速標示重點。
- 清單可用來整理多個項目。
- 連結會在點選後開啟，例如[Markdown 指南](https://commonmark.org/help/)。

```swift
let readingMode = "focused"
let keepsImageAspectRatio = true
```

| 顯示模式 | 文字閱讀欄 | 圖片行為 |
| --- | --- | --- |
| 全局模式 | 約 20 個中文字；過小時隱藏 | 持續等比例縮小 |
| 單一面板 | 約 40 個中文字 | 不超出閱讀欄 |

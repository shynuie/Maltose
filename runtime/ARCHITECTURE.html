MyAgent Architecture

從使用者命令、語音處理、TaskBrain 規劃，到 worker 執行與語音回覆。

目前有幾個 Planner、Worker？

Planner：1 個

TaskBrain 內的 LLM tool loop。它決定直接回答、呼叫工具、建立 task plan，或建立 schedule。

Worker：3 類

codex_readonly、可選的 web_research、assistant_message。它們由 TaskManager 的 bounded pool 執行。

Scheduler：1 個

TaskManager 啟動一條 scheduler thread，每 0.5 秒檢查 SQLite 中到期的排程。

目前的核心限制

  • 一個 TaskBrain planner，透過 tool call 建立普通 Task 或 Schedule；沒有多 planner 協作。
  • Schedule 的 completed 代表「已觸發並建立 Task」，底層 Task 仍有自己的 succeeded／failed 狀態。
  • 排程通知在安全的 TTS 邊界播報，不會中斷正在進行的語音。
  • SQLite 狀態可保留，但 process restart 後的執行中 Task recovery 與通知 replay 尚未完成。

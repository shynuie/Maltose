# 純 UI／原生 Glass／自動全螢幕驗證

日期：2026-10-31。基準 commit：`8a73e7c`。規格見 [計劃](../../plans/glass-workspace.md)。本文件取代先前記憶體 Host 探索稿的驗證紀錄。

## 本輪變更

- 新 App 啟動入口只建立原生 UI，不啟動舊 Host、Agent、資料庫、Keychain 或 WebSocket。
- 面板 Content 改為原生示意元件，不使用舊 WebKit／MUP renderer。舊 Host 與 SDK 原始碼保留但不由 UI 呼叫。
- 一般 Glass 邊距由 20 增至 36 pt，主面板由 10 增至 24 pt，縮圖由 8 增至 12 pt。
- macOS 26+ 改用 `NSGlassEffectView` regular Liquid Glass，淡藍 tint，移除 alpha 0.80 的實色藍色覆蓋。macOS 14–25 使用原生模糊材質降級。
- 面板選取時以 Liquid Glass 的淡藍 tint 高光；恢復窗口／選取的原生材質呈現，不覆蓋固定色層。
- 一般／主面板內容隨尺寸重新排列；縮圖對完整內容畫面等比例縮小，不裁切或改變比例。
- 窗口自動呼叫 `toggleFullScreen`，依序進入原生全螢幕 Space。動畫期間停止強制還原 frame，避免和 AppKit 動畫互相干擾。
- 非原生全螢幕／失敗降級使用半透明黑色（alpha 0.60）與桌面模糊，原生全螢幕維持黑底。

## 測試與畫面檢查

本次工作空間驗證合計 15 項通過、0 失敗，涵蓋幾何、滾輪路由、縮放錨點、原生窗口、全屏、Content 保留與 30 面板滾動；明細見下方「全局模式與固定區驗證更新」。

- 5 個狀態／幾何案例：主面板移除後接替、排列穩定、左緣靜止計時重設、不同螢幕比例下等大且不重疊、完整縮圖等比例置中。
- 原生 UI 案例：視窗模式下的半透明背景、加寬的外框與內容點擊範圍；切換主面板、縮圖與跨螢幕移動後重用同一個 Content，實際筆記文字保留。
- 原生全螢幕案例：在目前兩個實體螢幕上啟動自動切換，確認 AppKit 的 `.fullScreen` 狀態與窗口的原生全螢幕完成狀態；不是只比較窗口與螢幕的 frame。
- 封裝版本已開啟並以原生畫面檢查四個示意面板、加寬的外框與系統 Glass。封裝不再包含 Host toolkit 或 renderer 資產。
- Release build 與本機 ad-hoc 簽章驗證通過。

## 全局模式與固定區驗證更新

- `scripts/swift-test.sh --filter WorkspaceLayoutTests`：14 項通過，覆蓋網格幾何、螢幕比例對應初始欄數、縮放滾動、事件路由、選取清除與多選狀態。
- 面板互動支援單選高光、工作區空白點擊清除、⌘ 點擊多選，以及選取集合跨窗口移動的原生測試案例。原生窗口測試在沒有 WindowServer 的執行環境會跳過；相關案例需在 macOS 桌面工作階段驗證。
- 主面板全屏與主面板＋側欄模式使用 canvas 內部座標，避免重複套用工作區的根視圖偏移；Glass 頂緣貼齊中間工作區頂端、底緣留在輸入區上方。全局網格與底部 chrome 維持原樣。原生幾何測試改以根視圖座標驗證；該測試需桌面工作階段執行。
- 全局與主面板全屏之間往返時，直接以原生面板做兩段式轉場：0.14 秒聚中，接著 0.58 秒以中心為軸縮放。動畫期間略過會覆寫 frame 的根視圖重排；不以快照代替原生 Glass，並尊重系統「減少動態效果」設定。
- 原生窗口測試新增三種模式的框架不變與中間區域限制斷言。此輪執行環境沒有可用的 WindowServer，4 項原生測試因此跳過；程式已成功編譯，需在 macOS 桌面工作階段重新執行該組測試。先前原生全屏、跨屏 Content 保留與 30 面板滾動測試曾在桌面工作階段通過。
- 原生 UI 檢視確認固定頂部狀態／提示、底部草稿輸入／設定；這兩個區塊在全局、主面板全屏及主面板＋側欄模式都維持相同位置與尺寸。提示可展開，設定占位頁可打開，輸入草稿在開啟設定後仍存在。
- 30 面板封裝預覽實測原生向下滾動後捲軸移至 0.77，再向上回到 0；方向與預期一致。檢查後恢復正式四面板預覽。
- 30 個示意面板可用預覽參數啟動：`--panel-count=30`。正式預覽仍保留原本四個示意面板。
- 最新純 UI app 與預覽 app 均已 Release build、簽章並通過驗證。

滾輪方向遵從 AppKit 送入應用程式的 `scrollingDeltaY`，macOS 依使用者目前的自然捲動偏好調整該值；不改動系統設定。實際靈敏度與錨點手感仍可在預覽中調整。

## 實際限制與待校正

- 純黑後景本身沒有可供折射／模糊的細節，原生 Glass 的通透感仍會比覆蓋在圖片或桌面上更含蓄。材質已交給系統繪製，具體 tint／對比可繼續校正。
- 多螢幕原生全螢幕依賴系統的獨立 Spaces 設定；未開啟時主要螢幕進入原生全螢幕，其他窗口作為輔助窗口。不修改使用者的系統設定。
- 本輪原生跨窗口測試在非全螢幕模式驗證內容與歸屬保留；原生全螢幕 Space 下的實際鼠標跨螢幕拖曳，以及螢幕熱插拔仍待真人試用。
- 使用者可用 `--windowed` 試用半透明黑色降級背景。所有原型內容與排列只在記憶體中，重啟即重設。
- 目前不接 Agent，也不提供任何 Agent 管理或授權入口。
